# 网络鲁棒性与节点攻击分析 (免费体验版)

此目录包含一个可运行的简化示例，用于展示基础的节点攻击流程与两个核心鲁棒性指标：
- 全局效率 (Global Efficiency)
- 最大连通子图规模 (Largest Connected Component Size)

## 包含内容
| 文件 | 作用 |
|------|------|
| `test_node_attack_free.m` | 入口脚本，展示随机攻击 vs 度攻击 vs 近似介数攻击曲线 |
| `core_attack_logic.m` | 核心循环逻辑示例 |
| `Approx_Node_Betweenness.m` | 免费版占位：近似介数 (度 + 噪声) |

## 与完整版差异
免费版特性:
- 攻击策略: 随机, 度, 近似介数
- 指标: 全局效率、最大连通子图规模
- 简化重复次数与近似排序
